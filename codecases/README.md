# 🎬 Movie Rating Analyser

### Python-Based Data Analysis Project

## 📌 Project Overview
The **Movie Rating Analyser** is a Python-based project designed to analyse movie ratings and provide meaningful insights into movie performance. It processes movie datasets, calculates rating statistics, identifies top-rated movies, and presents useful information through data analysis and visualizations.

The project demonstrates the practical application of Python programming, data analysis, data manipulation, and visualization techniques.

## 🎯 Objectives
- Analyse movie ratings from a dataset.
- Identify the highest-rated and lowest-rated movies.
- Calculate average movie ratings.
- Find the most popular movies based on user ratings.
- Compare movie ratings across different genres.
- Generate meaningful insights using data visualization.

## 🛠️ Technologies Used
- **Python3**– Core programming language
- **Pandas** – Data manipulation and analysis
- **Matplotlib** - charts and histograms
- **CSV** - to store movies name genre rating
- **Git and GitHub** - maintain the project source code and documentation

## ⚙️ Key Features
1. **Movie Data Analysis:** Reads and processes movie datasets.
2. **Rating Analysis:** Calculates average, maximum, and minimum ratings.
3. **Top-Rated Movies:** Displays movies with the highest ratings.
4. **Genre Analysis:** Compares ratings across different movie genres.
5. **Popularity Analysis:** Identifies movies with the highest number of ratings.
6. **Data Visualization:** Generates graphs and charts for better understanding.
7. **Statistical Insights:** Provides useful information based on movie rating patterns.

## 🚀 Installation and Setup

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd Movie-Rating-Analyser
```

**3. Install required libraries**

```bash
pip install -r requirements.txt
```

**4. Run the project**

```bash
python src/analyser.py
```
